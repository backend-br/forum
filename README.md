# Fórum

Dúvidas, sugestões e questões em gerais sobre backend.

## Resumo da semana

Todo domingo, às 21h, uma discussion na categoria **Geral** reúne o que entrou na comunidade nos últimos 7 dias: as
vagas verificadas do [backend-br/vagas](https://github.com/backend-br/vagas), os perfis novos com divulgação autorizada
do [backend-br/me-contrata](https://github.com/backend-br/me-contrata), as soluções aceitas nos
[desafios](https://github.com/backend-br/desafios) e as contribuições aceitas no
[opensource-br](https://github.com/backend-br/opensource-br). O resumo é montado sem IA, e uma semana sem novidades não
gera discussion. Cada resumo termina com `Válida até` no dia do próximo, e o resumo novo fecha os anteriores como desatualizados, então o
site deixa de mostrá-los quando o seguinte chega.

## Destaques

O site lista as discussions abertas em [backend-br.github.io/forum](https://backend-br.github.io/forum/), das mais
recentes às mais antigas. Uma discussion vai para o topo dessa página quando uma pessoa mantenedora aplica o label
`destaque`, e fica lá mesmo fechada ou bloqueada. Quem abre a discussion pode pedir o destaque, mas só o label o
concede.

Para o destaque acabar em uma data, escreva esta linha no corpo da discussion:

```text
Destaque até: 09/11/2026
```

Um destaque com data também aparece na home. Ele some no primeiro build do site depois das 23h59 desse dia, no horário de
Brasília. Sem essa linha, o destaque fica sempre no topo do fórum, mas não vai para a home. Uma data escrita de outro jeito, ou que não existe, não destaca a discussion.

Para o botão principal do destaque levar a um endereço fora do fórum, como um formulário, acrescente esta linha:

```text
Link: https://exemplo.com.br/
```

Depois que o destaque acaba, a discussion continua listada no site com as demais, se ainda estiver aberta.

## Validade

Para uma discussion sair do site depois de uma data, com ou sem destaque, escreva esta linha no corpo:

```text
Válida até: 15/11/2026
```

Ela some no primeiro build do site depois das 23h59 desse dia, no horário de Brasília, e continua no fórum. Uma data
escrita de outro jeito mantém a discussion no site.
